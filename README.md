# Práctica de Gramáticas

Página web interactiva para estudiar el tema de gramáticas.

## Contenido
- 50 preguntas de selección múltiple.
- Explicación paso a paso de cada respuesta.
- Temas: definición de gramática G = (V, T, S, P), producciones, derivaciones (⇒ y ⇒*), lenguaje generado L(G), gramáticas regulares y libres de contexto.
- Puntaje final con nota sobre 5,00 y opción de repetir solo las preguntas falladas.

## Cómo usarla
Abre `index.html` en el navegador. No necesita servidor ni instalación.
